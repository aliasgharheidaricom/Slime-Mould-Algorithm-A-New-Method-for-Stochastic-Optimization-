

# Algoritmo de moho de limo: Un nuevo método para la optimización estocástica

En este artículo, se propone un nuevo optimizador estocástico, llamado algoritmo de moho de limo (SMA), basado en el modo de oscilación del moho de limo en la naturaleza. El SMA propuesto presenta varias características nuevas con un modelo matemático único que utiliza pesos adaptativos para simular el proceso de generación de retroalimentación positiva y negativa de la onda de propagación del moho de limo, basado en un biooscilador, para formar la ruta óptima para conectar el alimento, con excelente capacidad de exploración y propensión de explotación. El SMA propuesto se compara con metaheurísticas actualizadas en un amplio conjunto de referencias para verificar su eficiencia. Además, se utilizan cuatro problemas clásicos de estructuras de ingeniería para estimar la eficacia del algoritmo en la optimización de problemas de ingeniería. Los resultados demuestran que el algoritmo propuesto se beneficia de un rendimiento competitivo y, a menudo, excepcional en diferentes paisajes de búsqueda. El código fuente y la información del SMA están disponibles públicamente en: http://www.aliasgharheidari.com/SMA.html
